# История и архив прототипа

Основная ветка содержит рабочий CLI, OCR-ядро, конфигурацию полей, тесты и проверяемую
демонстрацию. Старая реализация сохранена в истории Git.

## Версия до очистки

[Тег archive/pre-cleanup-2026-10-22](https://github.com/place3/RateScaner/tree/archive/pre-cleanup-2026-10-22)
фиксирует состояние перед очисткой дерева. Там доступны:

- `GUI/` — незавершённый интерфейс CustomTkinter и его предыдущие версии.
- `db_dir/`, `work_w_db.py` — ранние реализации SQLite и Excel.
- `numsAndX.py`, `CNNModel/numsAndX.py`, `fix.py` — эксперименты с предобработкой.
- `nums/` — вырезанные изображения символов.
- `scans/` — прежний набор изображений и PSD.
- `user_table/` — промежуточный результат Excel.

Два бланка, используемые актуальной демонстрацией, перенесены в
[`examples/protocol_demo/input/`](../examples/protocol_demo/input/). Они не удалены.
Сгенерированный Excel демонстрации также остаётся в `examples/protocol_demo/`.

Из актуальной версии исключены пустые файлы-заготовки, старые БД, кэш Python и
неиспользуемый файл `requirements`. Для установки используется `requirements.txt`.
Изменения дерева не очищают и не переписывают историю Git.

## Посмотреть старый файл локально

```bash
git fetch origin tag archive/pre-cleanup-2026-10-22
git show archive/pre-cleanup-2026-10-22:GUI/App_v2.0.py
```

Снимок `code only/` и файлы IDE были исключены раньше. Их можно найти в более ранних
коммитах; в теге перед этой очисткой они уже отсутствуют.
